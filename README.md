# Fume

A WebGPU soap-film and smoke toy. Blow bubbles, place fans and vents, and drag a stone corridor so the smoke moves with the room.

## Run

```bash
npm install
npm run dev
```

Open the printed local URL in Chrome or Edge. WebGPU is required.

The lab (controls in the corner) has moods, the corridor (layers, depth, where the smoke sits), and light shafts.
